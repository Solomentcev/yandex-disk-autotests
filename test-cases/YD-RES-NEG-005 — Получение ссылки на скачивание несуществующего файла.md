# YD-RES-NEG-005 — Получение ссылки на скачивание несуществующего файла

**Тип:** Regression

**Описание:**
Проверка обработки запроса ссылки на скачивание файла, отсутствующего на Яндекс Диске.

### Предусловия

1. Пользователь авторизован в API Яндекс Диска.
2. OAuth-токен доступен тестам.
3. API Яндекс Диска доступно.
4. Файл `/autotests/<unique-test-id>/test-file.txt` отсутствует.

### Тестовые данные

| Параметр            | Значение                                    |
| ------------------- | ------------------------------------------- |
| Несуществующий файл | `/autotests/<unique-test-id>/test-file.txt` |
| Endpoint            | `GET /v1/disk/resources/download`           |

### Шаги

|  № | Действие                                                                                                  | Ожидаемый результат                    |
| -: | --------------------------------------------------------------------------------------------------------- | -------------------------------------- |
|  1 | Отправить `GET /v1/disk/resources/download` с параметром `path=/autotests/<unique-test-id>/test-file.txt` | Сервер возвращает HTTP `404 Not Found` |

### Постусловия

Не требуются. Тестовые ресурсы не создаются.
