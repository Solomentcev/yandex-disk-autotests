# YD-TRASH-001 — Работа с удалённым ресурсом в Корзине

**Тип:** Regression

**Описание:**
Проверка удаления файлового ресурса в Корзину, проверки сохранения исходного пути, восстановления ресурса в исходное расположение и его окончательного удаления.

### Предусловия

1. Пользователь авторизован в API Яндекс Диска.
2. OAuth-токен доступен тестам.
3. API Яндекс Диска доступно.

### Тестовые данные

| Параметр                | Значение                                    |
|-------------------------|---------------------------------------------|
| Тестовый каталог        | `/autotests/<unique-test-id>`               |
| Тестовый файл           | `/autotests/<unique-test-id>/test-file.txt` |
| Имя файла               | `test-file.txt`                             |
| Содержимое файла        | Подготовленное тестовое содержимое          |
| Endpoint ресурсов       | `/v1/disk/resources`                        |
| Endpoint загрузки       | `/v1/disk/resources/upload`                 |
| Endpoint Корзины        | `/v1/disk/thrash/resources`                 |
| Endpoint восстановления | `/v1/disk/thrash/resources/restore`         |

### Шаги

|  № | Действие                                                                                                                                                 | Ожидаемый результат                                                        |
|---:|----------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------|
|  1 | Отправить `PUT /v1/disk/resources?path=/autotests/<unique-test-id>` для создания каталога                                                                | Сервер возвращает HTTP `201 Created`. Каталог создан                       |
|  2 | Отправить `GET /v1/disk/resources/upload?path=/autotests/<unique-test-id>/test-file.txt` для получения ссылки на загрузку                                | Сервер возвращает ссылку `href`                                            |
|  3 | Выполнить `PUT` по полученному `href`, передав содержимое тестового файла                                                                                | Файл успешно загружен                                                      |
|  4 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` для проверки файла перед удалением                                     | Сервер возвращает HTTP `200 OK`; файл существует                           |
|  5 | Отправить `DELETE /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` без `permanently=true`                                              | Файл удалён из исходного расположения и помещён в Корзину                  |
|  6 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` для проверки исходного расположения                                    | Сервер возвращает HTTP `404 Not Found`; файл отсутствует                   |
|  7 | Отправить `GET /v1/disk/thrash/resources` для получения содержимого Корзины                                                                              | Сервер возвращает содержимое Корзины                                       |
|  8 | Найти удалённый `test-file.txt` в полученном содержимом                                                                                                  | Удалённый файл присутствует в Корзине                                      |
|  9 | Проверить `origin_path` удалённого файла                                                                                                                 | `origin_path = disk:/autotests/<unique-test-id>/test-file.txt`             |
| 10 | Отправить `PUT /v1/disk/thrash/resources/restore?path=<path-в-корзине>` для восстановления файла                                                         | Ресурс успешно восстановлен                                                |
| 11 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` для проверки восстановления                                            | Сервер возвращает HTTP `200 OK`; файл снова находится по исходному пути    |
| 12 | Проверить метаданные восстановленного файла                                                                                                              | `type = file`; `name = test-file.txt`; `path` соответствует исходному пути |
| 13 | Отправить `DELETE /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt&permanently=true` для окончательного удаления восстановленного файла | Файл удалён без помещения в Корзину                                        |
| 14 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt`                                                                        | Сервер возвращает HTTP `404 Not Found`; файл отсутствует                   |

### Постусловия

Если тест завершился до выполнения штатного удаления, `TestDataExtension` удаляет оставшиеся тестовые ресурсы и очищает связанные данные из Корзины.
