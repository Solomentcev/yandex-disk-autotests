# YD-RES-NEG-003 — Повторное создание существующего каталога

**Тип:** Regression

**Описание:**
Проверка обработки повторной попытки создания уже существующего каталога.

### Предусловия

1. Пользователь авторизован в API Яндекс Диска.
2. OAuth-токен доступен тестам.
3. API Яндекс Диска доступно.
4. Тестовый каталог `/autotests/<unique-test-id>` отсутствует.

### Тестовые данные

| Параметр         | Значение                      |
| ---------------- | ----------------------------- |
| Тестовый каталог | `/autotests/<unique-test-id>` |
| Endpoint         | `PUT /v1/disk/resources`      |

### Шаги

|  № | Действие                                                                                           | Ожидаемый результат                                  |
| -: | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
|  1 | Отправить `PUT /v1/disk/resources` с параметром `path=/autotests/<unique-test-id>`                 | Сервер возвращает HTTP `201 Created`, каталог создан |
|  2 | Повторно отправить `PUT /v1/disk/resources` с тем же параметром `path=/autotests/<unique-test-id>` | Сервер возвращает HTTP `409 Conflict`                |

### Постусловия

Тестовый каталог удаляется `TestDataExtension`.
