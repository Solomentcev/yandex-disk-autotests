# YD-RES-NEG-001 — Получение несуществующего ресурса

**Тип:** Regression

**Описание:**
Проверка получения метаданных ресурса, отсутствующего на Яндекс Диске.

### Предусловия

1. Пользователь авторизован в API Яндекс Диска.
2. OAuth-токен доступен тестам.
3. API Яндекс Диска доступно.
4. Тестовый ресурс отсутствует на Яндекс Диске.

### Тестовые данные

| Параметр                     | Значение                      |
| ---------------------------- | ----------------------------- |
| Путь несуществующего ресурса | `/autotests/<unique-test-id>` |
| Endpoint                     | `GET /v1/disk/resources`      |

### Шаги

|  № | Действие                                                                           | Ожидаемый результат                    |
| -: | ---------------------------------------------------------------------------------- | -------------------------------------- |
|  1 | Отправить `GET /v1/disk/resources` с параметром `path=/autotests/<unique-test-id>` | Сервер возвращает HTTP `404 Not Found` |

### Постусловия

Не требуются. Тестовые ресурсы не создаются.
