# YD-RES-NEG-006 — Изменение свойств несуществующего ресурса

**Тип:** Regression

**Описание:**
Проверка обработки попытки изменения пользовательских свойств ресурса, отсутствующего на Яндекс Диске.

### Предусловия

1. Пользователь авторизован в API Яндекс Диска.
2. OAuth-токен доступен тестам.
3. API Яндекс Диска доступно.
4. Ресурс `/autotests/<unique-test-id>/test-file.txt` отсутствует.

### Тестовые данные

| Параметр                  | Значение                                    |
| ------------------------- | ------------------------------------------- |
| Несуществующий ресурс     | `/autotests/<unique-test-id>/test-file.txt` |
| Пользовательское свойство | `testKey=testValue`                         |
| Endpoint                  | `PATCH /v1/disk/resources`                  |

### Шаги

|  № | Действие                                                                                                                                         | Ожидаемый результат                    |
| -: | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
|  1 | Отправить `PATCH /v1/disk/resources` с параметром `path=/autotests/<unique-test-id>/test-file.txt` и `custom_properties={"testKey":"testValue"}` | Сервер возвращает HTTP `404 Not Found` |

### Постусловия

Не требуются. Тестовые ресурсы не создаются.
