# YD-RES-001 — Работа с файловым ресурсом

**Тип:** Regression

**Описание:**
Проверка создания каталога и файлового ресурса, получения и проверки метаданных, скачивания файла с проверкой содержимого, изменения пользовательских свойств и окончательного удаления ресурса без помещения в Корзину.

### Предусловия

1. Пользователь авторизован в API Яндекс Диска.
2. OAuth-токен доступен тестам.
3. API Яндекс Диска доступно.

### Тестовые данные

| Параметр            | Значение                                    |
|---------------------|---------------------------------------------|
| Тестовый каталог    | `/autotests/<unique-test-id>`               |
| Тестовый файл       | `/autotests/<unique-test-id>/test-file.txt` |
| Имя файла           | `test-file.txt`                             |
| Содержимое файла    | Подготовленное тестовое содержимое          |
| `custom_properties` | `{"testKey": "testValue"}`                  |
| Endpoint ресурсов   | `/v1/disk/resources`                        |
| Endpoint загрузки   | `/v1/disk/resources/upload`                 |
| Endpoint скачивания | `/v1/disk/resources/download`               |

### Шаги

|  № | Действие                                                                                                                                    | Ожидаемый результат                                                                                                                           |
|---:|---------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Отправить `PUT /v1/disk/resources?path=/autotests/<unique-test-id>` для создания каталога                                                   | Сервер возвращает HTTP `201 Created`. Каталог создан                                                                                          |
|  2 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>` для проверки созданного каталога                                        | Сервер возвращает HTTP `200 OK`; `type = dir`; `path` соответствует ожидаемому                                                                |
|  3 | Отправить `GET /v1/disk/resources/upload?path=/autotests/<unique-test-id>/test-file.txt` для получения ссылки на загрузку файла             | Сервер возвращает ссылку `href`                                                                                                               |
|  4 | Выполнить `PUT` по полученному `href`, передав содержимое тестового файла                                                                   | Файл успешно загружен                                                                                                                         |
|  5 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` для проверки загруженного файла                           | Сервер возвращает HTTP `200 OK`; `type = file`; `name = test-file.txt`; `path` соответствует ожидаемому; размер соответствует исходному файлу |
|  6 | Отправить `GET /v1/disk/resources/download?path=/autotests/<unique-test-id>/test-file.txt` для получения ссылки на скачивание               | Сервер возвращает ссылку `href`                                                                                                               |
|  7 | Выполнить `GET` по полученному `href` для скачивания файла                                                                                  | Сервер возвращает HTTP `200 OK` и содержимое файла                                                                                            |
|  8 | Сравнить скачанное содержимое с исходным содержимым                                                                                         | Содержимое полностью совпадает                                                                                                                |
|  9 | Отправить `PATCH /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` с телом `{"custom_properties":{"testKey":"testValue"}}` | Пользовательское свойство успешно добавлено                                                                                                   |
| 10 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` для проверки изменения                                    | Сервер возвращает HTTP `200 OK`; `custom_properties.testKey = testValue`                                                                      |
| 11 | Отправить `DELETE /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt&permanently=true` для окончательного удаления файла     | Файл удалён без помещения в Корзину                                                                                                           |
| 12 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>/test-file.txt` для проверки удаления                                     | Сервер возвращает HTTP `404 Not Found`; файл отсутствует                                                                                      |
| 13 | Отправить `DELETE /v1/disk/resources?path=/autotests/<unique-test-id>&permanently=true` для удаления тестового каталога                     | Каталог удалён                                                                                                                                |
| 14 | Отправить `GET /v1/disk/resources?path=/autotests/<unique-test-id>` для проверки удаления каталога                                          | Сервер возвращает HTTP `404 Not Found`                                                                                                        |

### Постусловия

Если тест завершился до выполнения штатного удаления, `TestDataExtension` удаляет оставшиеся тестовые ресурсы окончательно.
