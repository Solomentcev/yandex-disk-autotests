# Yandex Disk API Autotests

Тестовый проект в рамках задания на вакансию Automation QA Engineer.

Автотесты REST API Яндекс Диска на Java с использованием JUnit 5 и REST Assured.

## Стек

Java 17 · JUnit 5 · REST Assured · Allure · Awaitility · Maven · Logback

## Покрытие

* работа с файловыми ресурсами: создание, загрузка, получение метаданных, скачивание и удаление;
* проверка содержимого загруженного файла и пользовательских свойств;
* работа с Корзиной: удаление, проверка, восстановление и окончательное удаление;
* негативные сценарии для несуществующих ресурсов и повторного создания каталога;
* проверка HTTP-статусов и ключевых данных ответов;
* автоматическая подготовка и очистка тестовых данных;
* ожидание завершения асинхронных операций API;
* Allure-отчётность и логирование HTTP-взаимодействия.

## Структура

```text
src/test/java/ru/yandex/disk
├── client       # API-клиент
├── config       # конфигурация
├── data         # тестовые данные
├── extensions   # подготовка и очистка данных
├── filters      # HTTP-логирование
├── specs        # REST Assured спецификации
└── tests        # автотесты
```

## Настройка

Перед запуском задайте OAuth-токен:

```bash
export YANDEX_DISK_TOKEN="your-token"
```

## Запуск

```bash
mvn clean test
```

## Allure

```bash
mvn allure:serve
```
